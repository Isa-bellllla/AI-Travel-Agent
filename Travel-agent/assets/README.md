# Travel imagery

`coast.png` and `culture.png` were generated specifically for this interface using OpenAI image generation. They are fictional editorial travel illustrations, not hotel photographs, property evidence, or guaranteed views at recommended hotels. The interface labels them as illustrative travel imagery. Local files are bundled so no external image CDN is required.

`style.css` and `.streamlit/config.toml` define the consistent light theme and high-contrast controls.
